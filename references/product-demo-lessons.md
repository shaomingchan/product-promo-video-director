# 产品宣传片实测笔记

[这份文档是什么]
    从本仓库 `demos/` 下三支真实成品反推出的产品宣传片规律，补上游通用 references 没覆盖的部分。

    - 是：产品宣传片（SaaS / 工具类）的实测基线 + 与通用规则的差异点 + 证明段的具体拍法
    - 不是：通用视频方法论。节奏档位、组件目录、追问问题库仍以上游 references 为准

[实测基线]

    | 片子 | 时长 | 视觉段落 | 主体段时长 | 收尾段时长 |
    |---|---|---|---|---|
    | goodtrans-50k-novel-promo | 50.0s | 8 | 4.4–6.5s | 13.5s |
    | goodtrans-delivery-proof | 23.0s | 6 | 3.3–5.5s | 2.6s |
    | goodtrans-master-grade-translation | 41.2s | 6 | 3.3–8.9s | 12.4s |

    可用的三个数：

    - 主体段落普遍落在 **3–9 秒**。超 9 秒的段落只出现在收尾。
    - 收尾段长度跟总时长走：23s 的片子收尾 2.6s，40–50s 的片子收尾 12–13.5s。
      别用固定值卡收尾——短片的品牌定格要短，长片才给得起 12s 的品牌 + 网址展示。
    - 三支都是 16:9 / 30fps。产品宣传片（官网内嵌、销售 deck、YouTube）没有看到 9:16 的需求。

    读数口径：段落数与各段时长是逐帧测量的精确值；段落“角色”（承诺 / 痛点 / 证明 / 品牌）是每个段落中点抽一帧判读的，不是逐帧全标注。

[骨架规律（三支完全一致）]

    承诺或痛点 → 证明（主体，占一半以上段落）→ 品牌结尾

    段落数分布：

    - 50s：8 段 = 1 承诺 + 1 痛点 + 5 证明 + 1 品牌
    - 23s：6 段 = 1 承诺 + 1 痛点 + 3 证明 + 1 品牌
    - 41s：6 段 = 1 承诺 + 1 场景 + 3 证明 + 1 品牌

    两条从数据里读出来的做法：

    - **证明段是主体，不是功能罗列段。** 每段展示一样真实的交付物或真实界面，一段一个可命名的承诺
      （实测那支 50s 就是四段四件事：Markdown / Clean TXT / Bilingual Review / Quality Report）。
    - **开头不做视觉奇观。** 三支的 hook 都是一句可验证的承诺（"一次提交" / "普通 AI 只给你一段文本"），
      第 2 段立刻把痛点摊开。观众是先被承诺抓住、再被痛点留住，不是先被画面震住。

[与上游通用规则的三个差异]

    1. 上游 pacing-rules 的 [平台对照] 写"产品宣传 30s：开头 3-5s + 结尾 2-3s CTA"。
       实测反例：50s 和 41s 两支的收尾段是 12–13.5s。**长片的品牌段要按段落给足，不要按 2-3s 卡。**

    2. 上游 [三档节奏] 把产品演示归进"教程型 · 中等密度"。
       实测：产品宣传片的密度高峰不在开头，在证明段——每 3–9 秒换一个证据，整片节奏由证据数量决定，
       不是由开头 hook 决定。**排节奏时先数证明段有几个，再决定总时长。**

    3. 上游强调 hook 定生死。产品宣传片里 hook 的作用是"说清承诺"，不是"制造刺激"。
       把 hook 做成视觉炫技，反而会把后面的证明段衬得像说明书。

[证明段怎么拍（产品宣传片特有）]

    - 素材来源：自己的产品截图、真实交付文件、真实输出片段。三支片子全部是这个路子，没有一张示意图。
    - 组件：文档卡片、仿真 UI、对比栏为主（`broll-ui.*` / `broll-charts.*`）。
    - 不需要：真人出镜、实拍、3D 场景。产品宣传片里这些是干扰项，不是加分项。
    - 证据要具体到能被读：真实字数、真实术语表、质量报告的评分行。
      越具体越可信——"50k 字符的翻译"比"高质量的翻译"有效一个数量级。

[复现方法]

    ```bash
    # 段落切点：逐帧视觉变化曲线（本仓库片子用这个）
    ffmpeg -i demo.mp4 -vf "select='gte(scene,0)',metadata=print:file=-" -f null -

    # 硬切场景检测（对剪接型视频有效）
    ffmpeg -i demo.mp4 -filter:v "select='gt(scene,0.35)',showinfo" -f null -
    ```

    注意：本仓库三支片子是渐变动效、没有硬切，`scene,0.35` 一个切点都抓不到。
    要定位段落边界得用逐帧 `scene_score` 曲线 + 自适应阈值（均值 + 1.5 倍标准差）。
